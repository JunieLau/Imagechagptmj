Image F · 修 MJ，还气质 Fix MJ, keep the look

Midjourney 的原图常常只错一两处。交给 GPT，错能修好，色彩、虚化和颗粒却一起变了。Image F 先测量原图、写好提示词；出图之后，再把改动以外的地方还原成 MJ 的样子。 A Midjourney original often fails in only one or two places. GPT can fix the mistake, and it also changes the colour, the blur and the grain. Image F measures the original and writes the prompt. After GPT, it restores the MJ look everywhere the fix did not reach.

01

气质在色彩、虚化和颗粒里The look lives in colour, blur and grain

导演守着的是一张画的气质：色调、焦点、颗粒。Midjourney 常在一两处失手——多出来的手指、错开的接缝、变形的手。这些是可以指出来的错。 A director is holding a grade, a focus and a grain. Midjourney usually misses in one or two places: an extra finger, a broken seam, a twisted hand. Those are mistakes you can point at.

把图交给 GPT，错可以修好。颜色、景深虚化和颗粒也会被改写。明暗和雾气往往一起变。修的是局部，整张画的气质换了。 Give the frame to GPT and the mistake can be corrected. The colour, the depth-of-field blur and the grain are rewritten too, and light and haze often go with them. The repair is local. The temperament of the picture is not.

02

两件事分开做Two jobs, kept apart

交给 GPT 之前。测量原图的色彩、焦点和颗粒，生成一段可以直接粘贴的完整提示词。除了只修错，还可以写「修错 + 换头」和「修错 + 换整个角色」。 Before GPT. It measures colour, focus and grain, and writes a complete prompt you can paste as it is. Besides a plain fix, it can write “fix + head swap” and “fix + full character swap”.

GPT 出图之后。两张图逐像素对齐，找出真正改过的地方。其余的颜色、明暗、雾气、虚化、颗粒回到 MJ 原图。 After GPT. It aligns the two images pixel by pixel and finds what really changed. Colour, light, haze, blur and grain everywhere else return to the MJ original.

03

从原图到还原From the original to the restore

主路是四步。标定、只还原风格、角色设定图在你需要时再打开。角色参考可以在换头之前就准备好。 The main path is four steps. Open calibration, style only, or the character sheet when you need them. A character reference can be ready before a head swap.

  1. 01

    MJ 出图MJ out

    从 Midjourney 原图开始。它是后面测量和还原的参照。 Start from the Midjourney original. It is the reference for the measurement and for the restore.

  2. 02

    页面 ① · 生成提示词Page ① · Generate prompt

    Image F 测量原图，写出给 GPT 的提示词。可以只修错，或修错并换头，或修错并换整个角色。2×2 宫格可以先切成四格。 Image F measures the original and writes the prompt for GPT: fix only, fix and swap the head, or fix and swap the whole character. A 2×2 grid can be split into four frames first.

  3. 03

    粘贴给 GPTPaste into GPT

    把提示词整段交给 GPT，用它出图。Image F 负责测量、写提示词，以及出图之后的还原。 Give the whole prompt to GPT and let GPT make the new image. Image F measures, writes the prompt, and restores after that image exists.

  4. 04

    页面 ② · 还原Page ② · Restore

    把 GPT 出图和 MJ 原图对齐。真正改过的地方留下，其余还原成 MJ 的色彩、明暗、雾气、虚化与颗粒。 Align the GPT image with the MJ original. Keep what was really changed. Restore MJ colour, light, haze, blur and grain everywhere else.

  5. +

    用得到再打开Open when you need them

    ③ 标定③ Calibration

    用你自己的「MJ 原图 + GPT 出图」，统计 GPT 稳定的偏色、颗粒和清晰度偏差。一般自动，越用越准。 From your own MJ original and GPT output, it learns GPT’s stable colour, grain and sharpness bias. Mostly automatic, and it improves with use.

    ④ 只还原风格④ Style only

    构图已经不同：四视图、设定图，或同一场景重画。按区域和远近分层迁移风格，不按像素位置对齐。 The composition is different: a 4-view sheet, a character sheet, or the same scene drawn again. Style moves by region and depth, not by pixel position.

    ⑤ 角色设定图⑤ Character sheet

    正面头像和四视图的提示词。做出来，当作换头或换整个角色的角色参考。可以在换头之前准备。 Prompts for a front portrait and a 4-view sheet. Make them, and use them as the character reference for a head swap or a full character swap. This can come before the swap.

在 Windows 上安装Install on Windows

Windows 10 / 11，64 位。推荐官方安装包 ImageF_V4.9_Setup.exe。离线安装，里面已有 Python 3.10、numpy、OpenCV、Pillow。若发布页上有更新的安装包，以 Releases 为准。 Windows 10 / 11, 64-bit. The recommended file is the official installer, ImageF_V4.9_Setup.exe. It installs offline and already includes Python 3.10, numpy, OpenCV and Pillow. If a newer installer appears, use Releases.

  1. 下载Download

    从 V4.9 发布页下载 ImageF_V4.9_Setup.exe，双击安装。只装给当前用户，不需要管理员权限。安装包里的核心模块是编译好的，功能和源码一致。 Download ImageF_V4.9_Setup.exe from the V4.9 release and double-click it. It installs for the current user only and does not need administrator rights. The core modules in the installer are compiled. They behave like the source.

  2. 若出现 SmartScreenIf SmartScreen appears

    安装包没有代码签名，Windows 可能会拦截。点「更多信息」，再点「仍要运行」。 The installer is not code-signed, so Windows may warn you. Choose More info, then Run anyway.

  3. 语言，以及演示Language, and the demos

    安装时会问用中文还是英文。之后可在侧栏底部切换。同一发布页有 ImageF_CN.mov 与 ImageF_EN.mov，各约 7.5 分钟，讲它如何工作，并带操作示范。校验值写在该发布说明里。 The installer asks for Chinese or English. You can switch later at the bottom of the sidebar. The same release includes ImageF_CN.mov and ImageF_EN.mov, about 7.5 minutes each: how it works, plus a tutorial. Checksums are in those release notes.

结果放在哪里Where results go

保存在安装文件夹里的 Output。工具里可以改到别的文件夹。4.9 以前的结果仍留在原来的「输出」文件夹，不会被挪走。 They are saved in the Output folder inside the install folder. You can choose another folder in the tool. Results from versions before 4.9 stay in the old 输出 folder and are not moved.

联网与更新Network and updates

使用时不联网，也不检查更新。想在有新版时收到通知：打开上游仓库，点 Watch → Custom → Releases。更新方法是下载新的安装包运行，原地升级，设置保留。 It does not connect to the internet while you use it, and it does not check for updates. To hear about a new version, open the upstream repository and choose Watch → Custom → Releases. To update, download the new installer and run it. It upgrades in place and keeps your settings.

也可以用源码跑Or run it from source

下载仓库，整个文件夹解压后双击 ImageF.bat。电脑上没有 Python 3.10 时，会只为当前用户安装，不需要管理员权限。源码不含离线安装文件，第一次运行会联网下载 Python 3.10.11 和 numpy、OpenCV、Pillow，大约 70 MB。这是使用过程中唯一会联网的情况。 Download the repository, unzip the whole folder, and double-click ImageF.bat. If Python 3.10 is missing, it is installed for the current user, with no administrator rights. The source has no offline installers, so the first run downloads Python 3.10.11 plus numpy, OpenCV and Pillow, about 70 MB. That first source run is the only time it connects to the internet.
